## Make it Your Own!
#### PREREQUISITES:
- Sign up for a Netlify account <a href='https://www.netlify.com'>HERE</a>
- Install Node JS in your computer <a href='https://nodejs.org/en/'>HERE</a>
#### PROCEDURE:
- Download the zip folder from Github and unzip it
Here is the link to download zip 👉
<a href='https://github.com/CleverProgrammers/react-portfolio'>HERE</a>
- Open the folder in VS Code
- Edit <code>public/resumeData.json</code> and add your personal details and projects
- Open terminal in VS Code
- RUN <code>npm init</code> , this command can be used to set up a new or existing npm package
- RUN <code>npm install</code> , this command pulls out all the require node modules
- RUN <code>npm run build</code>, this command will create a build folder for you
- DRAG AND DROP the BUILD folder on Netlify, your app is live now for the world to see

## Changelog

### 2026-08-20 — Toolchain migration: Create React App → Vite, Node 22

Netlify warned that the project was still building on **Node.js 12**. Simply
raising the Node version was not possible: `react-scripts` 3.4.3 builds with
webpack 4, which asks OpenSSL for the MD4 hash that OpenSSL 3 removed, so the
build fails on modern Node with `ERR_OSSL_EVP_UNSUPPORTED`. Create React App
was also deprecated by the React team in February 2025, so moving to
`react-scripts` 5 would only have deferred the problem. The project was moved
to Vite instead.

**Build tooling**

| Before | After |
| --- | --- |
| `react-scripts` 3.4.3 | `vite` 7 + `@vitejs/plugin-react` |
| `react-scripts test` (Jest) | `vitest` + `@testing-library/react` |
| output → `build/` | output → `dist/` |
| `public/index.html`, `%PUBLIC_URL%` | root `index.html`, absolute `/` paths |
| JSX in `.js` files | JSX in `.jsx` files (required by Vite) |

- Added `netlify.toml` pinning `NODE_VERSION = "22"`, setting `publish = "dist"`,
  and adding the SPA fallback redirect that `/resume` needs to survive a direct
  visit or refresh. `.nvmrc` matches, for local work.
- `stackbit.config.ts` `nodeVersion` raised from 18 to 22.

**Runtime dependencies**

- **React 16.13 → 19** — `ReactDOM.render` replaced with `createRoot`.
- **react-router-dom 5 → 7** — `<Switch>` → `<Routes>`, `component={X}` →
  `element={<X />}`.
- **jquery removed** as an npm dependency — the single `$.ajax` call fetching
  `resumeData.json` is now `fetch`, and its failure path logs to the console
  instead of raising a blocking `alert()`. The global jQuery theme layer
  (flexslider, waypoints, fittext, magnific-popup) loaded from `index.html` is
  unchanged; it still drives the Ceevee theme.
- **react-ga removed** — it was imported but never called, and it targets
  Universal Analytics, which stopped processing data in July 2023. Google
  Analytics 4 would need `react-ga4` if analytics are wanted again.
- **react-typist removed** — unmaintained and incompatible with React 18+.
  Replaced by a local `src/Components/Typist.jsx` (~30 lines) that reproduces
  the typing effect and honours `prefers-reduced-motion`.
- **`registerServiceWorker.js` removed** — a Create React App 1.x relic that
  was registering a service worker no longer generated by the build.

**Repository hygiene**

- `build/` untracked (127 files). It was committed despite being listed in
  `.gitignore`, which only ever applies to untracked files.
- `.env` removed. It held `CI=false npm run build`, which was not an
  environment variable and duplicated a flag already in the `build` script.
- `.gitignore` now ignores `dist/` and all `.env` files.

**Dead code removed**

`App.try()` pushed onto `this.props.history`, but `App` renders *outside* its
own `<Router>`, so that prop never existed. It was passed to `About` as
`routeResume`, assigned to an unused variable, and the "Download Resume"
button it was meant to drive is an `<a>` with no `href`. The plumbing is gone;
the markup is untouched.

**Result:** 159 packages and **0 known vulnerabilities**, down from roughly
1,500 packages. Production build takes ~1.1s; the dev server starts in ~280ms.

> **Note:** the "Make it Your Own!" instructions above are inherited from the
> upstream template and are now out of date — the build output folder is
> `dist/`, not `build/`, and deploys happen from GitHub rather than by dragging
> a folder onto Netlify.
